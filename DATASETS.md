# Dataset Attribution

The dataset used in our experiments is obtained from the dataset release associated with FMWF.

- Original repository: [WW-Meng/FMWF](https://github.com/WW-Meng/FMWF)
- Original publication: Wenwen Meng, Chuan Ma, Ming Ding, Chunpeng Ge, Yuwen Qian, and Tao Xiang, “Beyond Single Tabs: A Transformative Few-Shot Approach to Multi-Tab Website Fingerprinting Attacks,” *Proceedings of the ACM Web Conference 2025*, pp. 1068–1077, 2025. [https://doi.org/10.1145/3696410.3714811](https://doi.org/10.1145/3696410.3714811)

Dataset availability and usage conditions should follow the original source. No dataset files are redistributed in this repository.
